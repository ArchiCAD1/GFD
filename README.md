# Gerardo Faustin Designs portfolio and project intake

This repository is a static GitHub Pages-compatible site. `index.html` is the portfolio and `start-project.html` is the six-step verified project-application experience.

## Local preview

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/index.html`. When Firebase is disabled, the wizard uses an explicit preview-verification mode and saves a preview submission only in local browser storage.

## Production configuration

Edit `site-config.js` with the public Firebase web configuration, reCAPTCHA Enterprise site key, and deployed Firebase Functions URLs. These values are public identifiers, not secrets. Email-provider credentials and any private keys belong in Google Secret Manager and must never be placed in this repository.

Production submission remains disabled in the checked-in configuration until the Firebase web app identifiers, App Check key, authenticated domains, and Gmail SMTP secrets have been configured. A deployable pricing seed is included at `firebase/seed/public-pricing.json`: USD 1.28/sq. ft. for residential and commercial work, with published low/high multipliers and zero-valued optional add-ons. The owner should review those business assumptions before the seed is published. Estimates use the entered fee-bearing programme area; circulation—including halls, corridors, stairs, landings, and connector areas—is recorded but excluded from that basis.

## Structure

- `experience.css` and `experience.js`: liquid-glass visual system, photo-depth parallax, and scroll weather phases.
- `application.css` and `application.js`: responsive wizard, validation, preview pricing, uploads, submission, and estimate download.
- `firebase-bridge.js`: passwordless email-link authentication, App Check, and immutable Storage uploads.
- `preliminary-pdf.js`: network-independent browser PDF fallback. The authoritative server PDF is generated by Firebase Functions.
